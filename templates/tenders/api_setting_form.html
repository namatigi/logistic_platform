Webhook (incoming orders)

Share this URL with the external system. It will POST closing order data here, and they appear on the Orders page. Right-click → Copy the URL.

Method: POST · Content-Type: application/json · no auth required. Supported fields: order_id, order_name, state, company_id, company_name, date_order, amount_total, customer, currency, cargo_reference, cargo_id, order_lines[].

If cargo_reference matches a tender reference returned by the API (e.g. CAR00014), the order is automatically linked to that tender.

Selcom payment callback

Selcom will POST payment results to this URL. Configure it as the callback URL when creating your Selcom checkout orders. CSRF is not required.
